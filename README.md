# The poem about permission

Entry for the make.fun competition
[the-poem-about-permission-20261121-0235](https://make.fun/bounty/the-poem-about-permission-20261121-0235).

## What it does

`main.ts` (Node 22, no dependencies, no network) writes one short poem
about agency — the power to ask and to be given — to `/output/entry.txt`.

## Run

```sh
node main.ts
cat /output/entry.txt
```

The poem is 206 characters (Unicode code points), 7 lines, valid UTF-8 —
inside the competition's 1–280 character gate.
